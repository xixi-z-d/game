# 微信原生小游戏

这是“ 一起画 ”的微信小游戏客户端原型，使用原生 Canvas 和微信小游戏 WebSocket API，不依赖 DOM 或第三方库。

## 导入开发者工具

1. 打开微信开发者工具，选择“小游戏”。
2. 导入目录：`C:\game1\minigame`。
3. 将 `project.config.json` 中的 `appid` 替换为你自己的小游戏 AppID；`touristappid` 只适合界面预览。
4. 在小游戏内打开“连接配置”，填写 WebSocket 地址。

本地开发时可以使用电脑局域网地址，例如：

```text
ws://192.168.1.100:8765/ws
```

微信开发者工具中可暂时关闭“校验合法域名、TLS 版本以及 HTTPS 证书”。真机和正式版本必须使用备案域名和有效 TLS 的 `wss://` 地址，并在微信公众平台配置合法域名。

## 当前原型功能

- 用户名密码注册和登录
- 本地大厅
- 创建六位房间码
- 使用房间码加入房间
- Canvas 触摸绘画和实时笔画同步
- 清空画布
- 聊天和猜词
- 回合、画手/猜手、计分和结束状态
- 断线有限次自动重连

客户端已提供“微信快捷登录”入口：调用 `wx.login()` 取临时 code，发送到服务端 `/_wechat_login?code=...`，取得短期 token 后通过 WebSocket `session_token` 首包认证。服务端未设置微信环境变量时会明确返回未配置错误；可继续用开发测试账号验证游戏协议。

## 启动本地后端

在项目根目录运行：

```bash
cd /c/game1
.venv/Scripts/python.exe -I game.py
```

服务端默认端口为 `8765`。小游戏开发者工具如果运行在同一台电脑上，可以填写：

```text
ws://127.0.0.1:8765/ws
```

真机不能访问 `127.0.0.1`，应填写电脑局域网 IP 或正式 WSS 地址。
